## event_type 枚举

| 类型 | 含义 | 数据源 |
|:-----|:-----|:-------|
| price_anomaly | 价格异动 | 行情API |
| volume_anomaly | 量能异动 | 行情API |
| board_anomaly | 板块异动 | 板块API |
| announcement | 公司公告 | CNINFO |
| regulatory | 监管事件 | CNINFO |
| policy | 政策变化 | 新闻/公告 |
| index_movement | 指数变动 | 行情API |
| sector_rotation | 板块轮动 | 板块API |
| capital_flow | 资金流向 | 板块API |
| news | 一般新闻 | TrendRadar |
| rule_change | 交易规则变化 | 公告 |
| technical_level | 接近技术位 | factor计算 |
| system_status | 系统运行状态 | 内部 |

## impact_direction 枚举

| 值 | 含义 |
|:---|:-----|
| bullish | 利多 |
| bearish | 利空 |
| neutral | 中性 |
| uncertain | 不确定 |

## impact_strength 枚举

| 值 | 含义 |
|:---|:-----|
| high | 可能改变持仓逻辑 |
| medium | 需要关注但不改变判断 |
| low | 归档级别 |

## impact_horizon 枚举

| 值 | 含义 |
|:---|:-----|
| intraday | 影响当日 |
| short_term | 1-5天 |
| medium_term | 1-4周 |
| long_term | 1月以上 |

## verification_status 枚举

| 值 | 含义 |
|:---|:------|
| verified | 已通过多源验证 |
| self_verified | 仅通过单源自检 |
| contradicting | 来源冲突 |
| pending | 待进一步确认 |
| outdated | 已过有效期 |

---

## 事件到信号的转换规则

```
EventRecord
  ├─ verification.status != "verified" → ❌ 不可生成信号
  ├─ timestamps.expires_at < now → ❌ 已过期
  ├─ signal_eligible == false → ❌ 不可生成信号
  │
  ├─ P0条件 → 🚨 立即推送 + 进入信号判断
  │
  ├─ P1条件 → ⚠️ 按规则推送 + 进入观察
  │
  ├─ P2条件 → 👀 进入观察清单（当天日终汇总）
  │
  └─ P3条件 → 📋 归档，不推送
```
