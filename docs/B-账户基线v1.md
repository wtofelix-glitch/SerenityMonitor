## 二、账户状态模型定义

Serenity内部维护一个`AccountState`对象，每次信号生成前加载。

### 2.1 核心数据结构

```
AccountState:
  total_assets: float            # 总资产
  total_market_value: float      # 总市值
  available_cash: float          # 可用现金
  frozen_cash: float             # 冻结资金（委托未成交）
  
  positions: list[Position]      # 持仓列表
    code, name, shares, available_shares
    cost_basis, current_price, market_value
    pnl, pnl_pct
  
  today_orders: list[Order]      # 当日委托
    code, side, price, quantity, status
  
  today_trades: list[Trade]      # 当日成交
    code, side, price, quantity, timestamp
  
  last_update: datetime          # 数据时间戳
  data_source: str               # manual/web/screenshot
  data_confidence: str           # high/mid/low
```

### 2.2 刚性风控规则

| 规则 | 阈值 |
|:----|:----:|
| 单票仓位上限 | **40%**（总资产）|
| 单行业仓位上限 | **60%** |
| 单笔最大亏损 | **总资产2%** |
| 账户最大回撤 | **-15%** |
| 可用现金下限 | **0** |

### 2.3 加仓条件（全部满足）
- 加仓后仓位 <= 40%
- 现有仓位盈利 >= 0
- 信号置信度 = 高
- 账户回撤 > -10%

### 2.4 减仓条件（满足任一）
- 单票仓位 > 40%
- 浮亏 > 8%
- 信号转空 → 减半仓

### 2.5 清仓/止损条件（满足任一）
- 触及止损线
- 不可逆转利空
- 信号连续3天强烈卖出

## 三、人工成交闭环

### 3.1 流程

```
Serenity发出建议 → 你确认 → 券商下单 → 回填成交 → 更新账户
```

### 3.2 回填命令

```
回填买入 600487 亨通光电 1500 55.23 14:45
回填卖出 601398 工商银行 1900 7.60 14:30
```

### 3.3 回填提醒
- 开盘前检查未回填→提示
- 回填后自动更新持仓+现金+风控计算
