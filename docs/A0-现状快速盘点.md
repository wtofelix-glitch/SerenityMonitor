## 二、数据流：当前实际路径

```
Sina API (实时)
  ↓ data_engine.fetch_realtime()
  ↓ 每分钟缓存
  ↓
config.py STOCK_MAP → 20只标的
  ↓
scorer.py score_all() (仅收盘后运行)
  ↓ 6维因子 → total_score
  ↓
signal_engine.py → 信号判定
  ↓
signal_push.py → 微信推送 (cron调度)
```

**关键问题**：盘中只有数据→看板映射，没有盘中信号生成。评分只在16:18+运行。
